# BountyOS v0.3 — интеграция сквозного сценария

## Добавлено
- Форма разрешённого актива в разделе «Программы».
- Создание отчёта через единый маршрут `POST /api/workflow/submit`.
- Проверка существования программы и точного совпадения актива с разрешённым scope до записи отчёта.
- Сравнение с отчётами той же программы и того же актива; порог сходства Jaccard >= 0.5. Это только кандидаты на ручную проверку, не автоматическое решение о дубликате.
- Автоматический расчёт и сохранение оценки приоритета, запись события `report_created`.
- Отображение предупреждений, если последующие этапы не завершились.

## Ограничения
- Учебный локальный прототип без входа, ролей, защиты персональных данных, очереди событий, повторных попыток и распределённых транзакций.
- После сохранения отчёта ошибка другого сервиса не откатывает запись. Повторная отправка создаёт новый отчёт.
- Доступен только для тестовых данных; нельзя публиковать в интернет или загружать реальные конфиденциальные отчёты.
- Не выполняет сканирование, проверяет только наличие актива в заданном вручную списке.

## Проверка
1. Запусти `python start.py` из папки BountyOS.
2. В «Программы» создай программу, скопируй её ID из таблицы.
3. Добавь разрешённый актив, например `demo.example.test`, с этим ID.
4. В «Отчёты» укажи ID программы и **точно такой же** актив, заполни остальные поля (важность и эксплуатируемость от 1 до 5).
5. Отправь отчёт и посмотри результат. Открой «Приоритеты» и «Аналитика» — появятся новые записи.
6. Отправь ещё один похожий отчёт по тому же активу — сравнение может показать кандидата на дубликат.

При обновлении распакуй v0.3 в **новую** папку. Чтобы перенести прежние тестовые данные, останови сервер и скопируй каталоги `data` из каждой из пяти старых папок сервисов в соответствующие папки новой версии. Перед копированием сделай резервную копию.
