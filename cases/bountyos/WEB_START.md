# BountyOS Web v0.2 — запуск на Windows

1. Открой папку `BountyOS` в VS Code.
2. Останови старый сервер BountyPulse (Ctrl+C в его терминале), чтобы освободить порт 8000 (новая версия использует другие порты, но старый процесс не нужен).
3. Открой терминал в корне `BountyOS`.
4. Установи зависимости:

```powershell
python -m pip install -r bountyos-web/requirements.txt
python -m pip install -r bounty-scope/requirements-dev.txt
```

5. Запусти все шесть процессов одной командой:

```powershell
python start.py
```

6. Открой http://127.0.0.1:8080

Для остановки нажми Ctrl+C. При ошибке `Address already in use` закрой ранее запущенный процесс на соответствующем порту.

## Что работает

- Единый браузерный интерфейс для пяти backend-сервисов.
- Создание и просмотр программ и отчётов.
- Сравнение текстов отчётов (упрощённый Jaccard; не AI).
- Оценка приоритетов и сохранение оценок.
- Ручное добавление событий и просмотр метрик.
- Данные хранятся в отдельных SQLite базах сервисов.

## Ограничения

- Это учебный прототип, не production. Нет авторизации, ролей, автоматического обмена событиями, защиты от злоупотреблений и полноценной проверки scope.
- Записи в разных сервисах пока не связаны транзакционно.
- Не загружай реальные конфиденциальные отчёты или данные клиентов.
- Веб-интерфейс сделан на HTML/CSS/JS без сборки; React + TypeScript — следующий этап.
