# BountyOS v0.4 — запуск и проверка

## Запуск на Windows

1. Остановите предыдущий BountyOS (`Ctrl+C` в терминале), чтобы освободить порты 8080, 8101–8105.
2. Распакуйте архив в **новую папку**, не поверх старой.
3. Откройте вложенную папку `BountyOS` в VS Code.
4. В терминале из папки `BountyOS` выполните:

```powershell
python -m pip install -r bountyos-web/requirements.txt
python -m pip install -r bounty-scope/requirements-dev.txt
python start.py
```

5. Откройте `http://127.0.0.1:8080` (если браузер не открылся автоматически).

## Тест без Swagger

1. Откройте «Программы». Две программы из присланного архива должны остаться на месте.
2. В форме «Добавить разрешённый актив» выберите одну из программ и укажите `demo.example.com`.
3. Откройте «Отчёты», выберите программу и актив. Заполните название, описание и критичность, нажмите «Отправить и обработать».
4. Откройте «Приоритеты» — должна появиться оценка P1–P4 и числовой балл.
5. Откройте «Аналитика» — должно появиться событие `report_created`.
6. Если отправить такой же отчёт повторно, в «Дубликаты» должен появиться кандидат на ручную проверку.

## Сохранность данных

В архив включены исходные SQLite-базы, в том числе две программы и один ранее созданный отчёт. **Старый отчёт не будет автоматически повторно обработан**: иначе возникли бы дублирующиеся записи. Перед дальнейшими изменениями сохраните резервную копию папок `data`.

## Ограничения

Это локальный учебный прототип, без авторизации, транзакций между сервисами и гарантированной идемпотентности. Не публикуйте сервер в Интернет и не используйте реальные конфиденциальные отчёты.
