# Cybersecurity Tools

Коллекция из пяти учебных инструментов для практики Python и кибербезопасности.

- LogSentinel — анализ SSH-логов.
- NetScope — проверка TCP-портов.
- WebGuard — анализ HTTP-заголовков безопасности.
- PCAP Analyzer — анализ сетевых дампов.
- PySentry — статический анализ Python-кода.

Проекты предназначены для обучения и локальных экспериментов.
Используйте сетевые проверки только на собственных системах
или с разрешения владельца.
